\# 🐱 赛程猫 (SaiChengMao)



> 一个面向备赛大学生的智能任务规划工具。



\## 项目介绍



赛程猫旨在帮助大学生管理竞赛、考研、项目等长期目标。



用户输入：

\- 目标名称

\- 截止日期

\- 任务列表



系统根据：

\- 剩余时间

\- 任务难度

\- 优先级

\- 当前进度



自动计算每天应该投入的时间，并推荐今日任务。
